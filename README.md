# kid-apps

## アプリ一覧

- [Meridian](https://maruflame.github.io/kid-apps/suuji-mori/)
  - iPhone では Safari で開いて 共有ボタン →「ホーム画面に追加」すると、全画面のアプリとして使えます。
  - 一度開いた画面と声は端末に保存され、オフラインでも遊べます（おとな設定の「声を ぜんぶ 保存する」で まだ鳴らしていない声も保存できます）。

## クレジット

- Meridian の読み上げ音声：VOICEVOX:ずんだもん（`python3 suuji-mori/make-voice.py` で作成）
